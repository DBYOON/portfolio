#### 개요

**품절 상품의 재입고 소식을 받을 수 있도록 상품 목록·상세의 알림 신청부터 마이페이지 내역 관리까지 프론트엔드를 구현하였습니다.**

**앱과 웹 환경에 맞는 신청 흐름을 제공하고, 알림 상태와 현재 품절 여부에 따라 재신청·취소·구매 이동을 연결하였습니다.**

#### 주요 작업

- 앱스킴 기반 앱 알림 설정 여부 확인 및 재입고 알림 신청 개발
- 앱스킴을 활용한 WebView ↔ Native 통신 구현
- 알림 상태별(대기/완료/만료/취소) 관리 UI 구현 및 재신청 · 구매 이동 · 취소 · 내역 삭제 기능 제공

### 화면 구성 및 UI 구현

- 상품 목록·상세에 신청 버튼을 추가하고, 품절 여부와 상품·배송 조건에 따라 노출을 제어하였습니다. 상세 진입 시 기존 신청 상태를 조회해 신청·신청 완료 UI를 구분하였습니다.
- 마이페이지에 알림 상태와 관련 날짜를 확인할 수 있는 내역 화면을 구현하고, 기존 상품 카드·장바구니 컴포넌트를 재사용하였습니다.
- 웹 신청 팝업을 공통화하고 완료 콜백을 제공해, 상세의 신청 상태 반영과 내역의 후속 처리를 각 화면에서 담당하도록 구성하였습니다.

마이페이지 내역 카드는 알림 상태에 따라 **상태 문구, 날짜 항목의 라벨과 값, 액션 버튼의 문구·동작·스타일**을 함께 변경하도록 구성하였습니다. 날짜 영역은 대기·만료 시 시작일과 종료일을, 완료·취소 시 해당 처리일 하나를 표시합니다.

| 알림 상태 문구 | 날짜 영역                  | 품절일 때 액션  | 품절이 아닐 때 액션 |
| -------------- | -------------------------- | --------------- | ------------------- |
| 알림 대기중    | 알림 기간: 시작일 ~ 종료일 | 알림받기 취소   | 알림받기 취소       |
| 알림 완료      | 발송일                     | 재입고 알림받기 | 지금 구매하기       |
| 알림기간 만료  | 알림 기간: 시작일 ~ 종료일 | 재입고 알림받기 | 지금 구매하기       |
| 알림받기 취소  | 취소일                     | 재입고 알림받기 | 지금 구매하기       |

- 상태 표시는 대기 중이면 연한 붉은색 배경·붉은색 글자, 완료·만료·취소이면 회색 배경·어두운 글자를 적용하였습니다.
- 액션은 취소 버튼에 회색 테두리, 재신청 버튼에 어두운 테두리·글자, 구매 링크에 붉은색 테두리·글자·화살표를 적용하였습니다. 재신청은 신청 조건을 충족하는 상품에만 노출하고, 구매 링크는 상품 상세로 연결하였습니다.
- 상품의 현재 품절 여부에 따라 이미지에 품절 오버레이를 표시하고, 판매 가능 여부와 대체 담기 조건에 따라 장바구니 버튼을 노출하였습니다.
- 삭제 모드에서는 선택 체크박스를 추가하고 카드 여백과 장바구니 버튼 위치를 조정하였습니다.

### 앱스킴 기반 WebView ↔ Native 통신

- 앱에서는 앱스킴으로 Native에 알림 설정 조회·변경과 재입고 신청을 요청하고, 웹에서는 공통 팝업과 API로 신청하도록 실행 경로를 분리하였습니다.
- Native의 비동기 결과 메시지에서 출처와 명령을 확인하고, 신청 완료·중복 신청·실패를 구분해 상태와 안내에 반영하였습니다.
- 앱 알림이 꺼진 경우 활성화 안내를 제공하고, 수신 동의 결과에 따라 배너와 동의 안내를 갱신하였습니다.
- 기능을 지원하는 앱 버전을 확인해 목록·상세의 신청 버튼과 마이페이지 메뉴 노출을 제어하였습니다.

**메시지 수신 및 이벤트 생명주기 관리**

수신 메시지의 출처와 명령을 확인한 뒤 결과 처리 함수로 전달하였습니다. 컴포넌트가 해제되면 이벤트 리스너를 제거하도록 구성하였습니다.

```tsx
useEffect(() => {
  const handleMessage = (event: MessageEvent<NativeResult>) => {
    if (event.origin !== window.location.origin) return;
    if (event.data.command !== 'NOTIFICATION_RESULT') return;

    handleResult(event.data);
  };

  window.addEventListener('message', handleMessage);

  return () => {
    window.removeEventListener('message', handleMessage);
  };
}, [handleResult]);
```

**신청 결과와 푸시 수신 동의 처리**

상세 화면에서는 신청 완료·중복 신청 시 신청 상태를 반영하였습니다. 신청 결과와 푸시 수신 동의 여부를 구분해, 신청에 실패한 경우에도 수신 동의 결과가 함께 전달되면 동의 일자를 포함해 안내하였습니다.

```tsx
const handleResult = ({ result, notificationId, pushAgree }: NativeResult) => {
  const consentDate = pushAgree === 'Y' ? today : undefined;

  switch (result) {
    case 'SUCCESS':
      showToast(messages.applied(consentDate));
      updateApplicationState(notificationId);
      break;

    case 'ALREADY_APPLIED':
      showToast(messages.alreadyApplied(consentDate));
      updateApplicationState(notificationId);
      break;

    default:
      showAlert(messages.failed(consentDate));
  }
};
```
