#### 개요

**방송 화면에 노출되는 별풍선 알림 애니메이션을 다양한 액션별로 설정할 수 있도록 관리 페이지의 UI와 사용성을 개선**

#### 주요 작업

- 별풍선 알림 효과를 사용자가 직접 설정할 수 있도록 스타일·테마·레이아웃·효과 옵션 선택 UI를 설계·퍼블리싱
- Animate.css를 활용해 알림 팝업의 IN / OUT 애니메이션 효과를 구현하고, 텍스트 노출 방향(정방향 / 역방향 / 랜덤)과 표시 방식을 설정값에 따라 제어할 수 있도록 JavaScript 로직 구성
- 설정 변경 결과를 즉시 확인할 수 있는 미리보기 기반 인터랙션 화면을 구현해 저장 전 효과를 직관적으로 검증할 수 있도록 개선
