#### 개요

**나의 다시보기 또는 BJ의 다시보기 중에 편집하고 싶은 구간을 업로드 VOD로 만들 수 있는 서비스**

#### 주요 작업

- 선택·제외 구간과 편집 가능 상태를 구분하는 타임라인 UI 구현
- 핸들 드래그와 분할 위치 선택을 처리하는 타임라인 인터랙션 로직 구현
- 구간 선택·경계 조정·분할·제거를 지원하는 편집 기능 구현
- 임시 데이터 기반으로 편집 흐름을 선구현해 화면 구조와 기능 동작을 사전 검증

**1. 선택·제외 구간과 편집 가능 상태를 구분하는 타임라인 UI 구현**

| 구분 | UI 적용 |
| --- | --- |
| 선택 구간 | 녹색 경계선으로 편집에 포함되는 범위 표시 |
| 제외 구간 | 반투명 음영으로 편집에서 제외되는 범위 표시 |
| 구간 경계 | 시작·종료 핸들로 조정 가능한 위치 표시 |
| 분할 위치 | 세로 기준선으로 사용자가 선택한 위치 표시 |
| 분할 상태 | 버튼의 활성·비활성 스타일로 실행 가능 여부 표시 |
| 편집 모드 | 컷 편집 종료 시 핸들과 분할 버튼 등 편집 요소 숨김 |

**2. 핸들 드래그와 분할 위치 선택을 처리하는 타임라인 인터랙션 로직 구현**

| 처리 단계 | 핵심 로직 |
| --- | --- |
| 핸들 선택 | 현재 조작 대상과 인접 구간 정보 저장 |
| 드래그 이동 | 마우스 위치를 타임라인 내부 좌표로 변환해 요소 위치 계산 |
| 인접 구간까지 드래그 | 핸들이 현재 구간을 벗어나면 이전·다음 구간으로 조작 대상을 전환해 연속 조정 |
| 타임라인 클릭 | 클릭 좌표를 분할 기준 위치로 설정 |
| 조작 종료 | 마우스를 놓으면 드래그 상태를 초기화하고 트랙 이탈 시 가이드선 숨김 |

**인접 구간까지 드래그 예시**

```text
① 드래그 시작

[구간 A] |핸들 1| [  구간 B  ] |핸들 2| [구간 C]
          └────────────→

② 핸들 2 경계 통과

[구간 A] [구간 B: 너비 0] |핸들 1·핸들 2| [구간 C]
                            └───────→
                            조작 기준: 핸들 2
```

핸들 1을 드래그해 구간 B를 지나 핸들 2의 경계를 넘으면 조작 대상을 핸들 2로 전환합니다. 사용자는 마우스를 다시 클릭하지 않고도 다음 구간까지 편집 범위를 계속 조정할 수 있습니다.

**3. 구간 선택·경계 조정·분할·제거를 지원하는 편집 기능 구현**

| 기능 | 구현 내용 |
| --- | --- |
| 구간 선택 | 컷 편집 시작 시 선택·제외 구간과 조작 핸들을 동적으로 생성 |
| 경계 조정 | 선택 구간과 인접 제외 구간의 크기를 함께 계산해 전체 길이 유지 |
| 구간 분할 | 분할 위치가 선택 구간 안에 있을 때 새 구간과 경계 요소 삽입 |
| 구간 제거 | 대상 구간을 삭제하고 인접 영역을 재계산해 빈 공간 없이 병합 |
| 전체 초기화 | 생성된 편집 요소를 정리하고 최초 선택 상태로 복원 |
