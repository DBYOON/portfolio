#### 개요

**나의 다시보기 또는 BJ의 다시보기 중에 편집하고 싶은 구간을 업로드 VOD로 만들 수 있는 서비스**

#### 주요 작업

- 영상 재생, 채팅, 타임라인, 편집 제어 영역을 포함한 VOD 편집기 전체 UI 구현
- JavaScript 기반 타임라인 핸들바 인터랙션 구현
- 구간 선택, 이동, 분할, 제거 등 편집 범위 제어 기능 구현
- 선택 구간, 분할 상태, 편집 가능 범위를 시각적으로 구분하는 UI 적용
- 임시 데이터 기반으로 편집 흐름을 선구현해 화면 구조와 기능 동작을 사전 검증
